Key Engineering Solutions

Challenge 1: Demoing without a live server.

Solution: Engineered a self-contained demo by embedding prediction data directly into the HTML.

Challenge 2: Infinitely extending graphs.

Solution: Fixed the layout by constraining the chart's container with CSS and updating Chart.js options.

Challenge 3: Uninformative average temperature.

Solution: Re-engineered the logic to display the daily min/max temperature range for a richer forecast.
